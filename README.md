# OOTP

This folder contains scripts and utilities related to OOTP baseball league operations, schedule generation, and league data processing.

## Scripts

- [ScheduleGenerator](./ScheduleGenerator/README.md) — Generates custom OOTP schedule XML files for multi-subleague, multi-division leagues, including balanced home/away splits, mixed series lengths, optional interleague play, and All-Star placement.

This top-level README is intentionally brief. Detailed usage, parameters, examples, and implementation notes live in each script's own README.
